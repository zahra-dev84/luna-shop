## Luna Shop | فروشگاه اینترنتی عروسک

**نوع پروژه:** توسعه وب Full-Stack

**فناوری‌ها:** PHP، MySQL، JavaScript، HTML5، CSS3، Bootstrap/Responsive Design، LocalStorage

**معرفی پروژه:**

طراحی و توسعه یک فروشگاه اینترنتی تخصصی محصولات عروسکی با هدف فراهم‌کردن بستری برای مشاهده، جست‌وجو و خرید محصولات و مدیریت سفارش‌های کاربران.

**امکانات و قابلیت‌های پیاده‌سازی‌شده:**

- طراحی رابط کاربری واکنش‌گرا برای نمایش مناسب در موبایل و دسکتاپ
- پیاده‌سازی صفحه اصلی شامل اسلایدر، دسته‌بندی محصولات و محصولات پرفروش
- توسعه قابلیت جست‌وجو، فیلتر و مرتب‌سازی محصولات
- پیاده‌سازی سبد خرید با استفاده از PHP Session
- امکان افزودن، حذف و ویرایش تعداد محصولات در سبد خرید
- پیاده‌سازی فهرست علاقه‌مندی‌ها با استفاده از LocalStorage
- طراحی سیستم ورود و ثبت‌نام کاربران
- اتصال وب‌سایت به پایگاه داده MySQL
- پیاده‌سازی فرایند ثبت سفارش و ذخیره اطلاعات سفارش‌ها
- طراحی بخش مدیریت برای مشاهده سفارش‌ها و جزئیات آن‌ها
- استفاده از JavaScript و Fetch API برای دریافت و نمایش اطلاعات محصولات

**بخش‌های فنی پروژه:**

- توسعه سمت کاربر (Frontend)
- توسعه سمت سرور (Backend)
- طراحی و مدیریت پایگاه داده
- مدیریت نشست کاربران و سبد خرید
- ارتباط بین بخش‌های مختلف وب‌سایت و پایگاه داده

**هدف از پروژه:** کسب تجربه عملی در توسعه یک وب‌سایت فروشگاهی و آشنایی با فرایندهای اصلی تجارت الکترونیک، از نمایش محصولات تا ثبت و مدیریت سفارش‌ها.
